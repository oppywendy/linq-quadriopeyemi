# Linq Frontend Engineer Interview Task

## Introduction
Hi, and thanks for your interest in joining our team at Linq!
We're not expecting a perfect solution. We're more interested in how you approach the problem, your ideas, and the quality of your code.
Try to spend just a couple of hours on this task. We understand your time is valuable, and everyone has a life outside of work.

Focus on showing us your strongest skills!

## The Challenge
We want you to create a single page application (SPA) using Reactjs (preferably) and/or other frontend tools. This SPA should allow users to explore the data provided by the API server.

Your SPA should go into the `client` folder, and we've provided the full API server code in the `server` folder for you to work with.

For details on the task and how to start, check out the [readme](./client/)!

## Running the API Server
In the `server` folder, you’ll find a simple REST API server built with NodeJS. This API gives data about flight journeys, which you can use to build the SPA.

Feel free to look at and make changes to the server code if you think it will help. However, the main focus for us will be on the SPA.

For details on how to run the server and the API documentation, check out the [readme](./server/)!
